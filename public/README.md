## RoomTune Homepage Assets

Drop real brand assets into this folder using the exact paths below.

### Required
- `logo.svg` - Header and footer logo.
- `hero.mp4` - Fullscreen landing video (muted loop, 16:9 or wider).
- `favicon.svg` - Browser tab icon.

### Screenshot slots (How it works)
- `screenshots/step-1.png` - Scan step screenshot.
- `screenshots/step-2.png` - Simulate step screenshot.
- `screenshots/step-3.png` - Optimize step screenshot.

### Visual showcase slots
- `footage/showcase-1.png`
- `footage/showcase-2.png`
- `footage/showcase-3.png`

### Optional
- `og-image.svg` - Social preview image for metadata shares.

If these files are missing, the homepage shows graceful placeholders.
